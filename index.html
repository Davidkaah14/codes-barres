Codes-barres produits

Recherche sur une copie d'Open Food Facts gardée sur votre appareil : aucune limite de requêtes, utilisable hors ligne. Choisissez un distributeur, une catégorie et un poids pour obtenir de vrais produits avec leur code-barres à scanner.

La base de données est introuvable
  1. Placez index_produits.js.gz (ou index_produits.js) dans le même dossier que cette page, sur votre hébergement.
  2. Rechargez la page. Vérifiez votre connexion si c'est la première ouverture.

Prenez le code-barres bien à plat, de près et net : l'appli en lit les chiffres, vérifie leur clé de contrôle puis redessine un code propre à imprimer. Formats pris en charge : EAN-13, EAN-8, UPC-A, UPC-E.

Placez le code-barres dans le cadre, bien éclairé.
